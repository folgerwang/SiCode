q4_matmul.comp
matmul_fp8.comp		 256 threads (8 warps), 1 row/warp, subgroupAdd. Reads X from global/L1 in every warp. Cache active X tile in shared vec4 Xs[] when NT >= 2; 128-thread WG or Split-K when gx < num_SMs. Up to 8× fewer X loads during MTP drafting; keeps all SMs busy on narrow Q/K/V layers.
q4_gemm.comp
gemm_fp8.comp		 Synchronous LDG → dequant → STS → BAR → FFMA → BAR. Power-of-2 Ws[32][16] stride. Coalesced raw block staging + Ws[32][17] (+1 pad) + register double-buffering of next tile k0 + BK. Eliminates SMEM store bank conflicts; overlaps global memory latency with FFMA.
gemm_coop.comp Ws, Ws2, Xs, Xl, Cs all live simultaneously (~37 KB SMEM/WG). Alias Cs over Ws/Xs after the K-loop finishes (<24 KB SMEM/WG). Doubles workgroups/SM (2+ WG/SM on 48–64 KB SMs) so warps switch across BAR.SYNC.
attention.comp shared float sacc[8][D] with power-of-2 row stride (D = 128/256). Pad to sacc[8][D + 4] for cross-subgroup head reduction. Eliminates bank conflicts during final attention output merge.
